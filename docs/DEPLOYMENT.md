# Deployment Guide

## 1. GitHub

Create a repository named `grashofstudio-web`, then push this project to `main`.

```bash
git remote add origin https://github.com/grashofstudio/grashofstudio-web.git
git push -u origin main
```

The repository includes six milestone commits for traceability.

## 2. Netlify

The production project is the existing **grashof** site in the Lattice Foundry team. It uses Netlify Drop, not a connected Git build. Do not create a second site.

1. Run `npm run quality` locally.
2. ZIP the contents of `dist/` (the ZIP root must contain `index.html`).
3. Upload that ZIP at `https://app.netlify.com/projects/grashof/deploys`.
4. Confirm the new deploy is **Published**, then verify `https://grashofstudio.com/`.

`public/_headers` is copied into the deploy and supplies the HTTP headers for Drop uploads. `netlify.toml` remains the build configuration if Git-based deployment is enabled later.

## 3. Domain

The existing domain is `grashofstudio.com`. Preserve its current DNS and Netlify domain settings; normal releases do not require domain changes. Prior deploys remain available for rollback.

## 4. Email

Before publishing the final Contact section, verify that this address can receive mail:

```text
hello@grashofstudio.com
```

A forwarding rule to the existing Gmail inbox is acceptable for the first release.

## 5. Pre-production checklist

- GitHub Actions CI is green
- Netlify Preview deploy succeeds
- `/`, two project pages, `/privacy/`, `/404.html`, and `/sitemap.xml` load
- Mobile layout has no horizontal overflow
- Videos load and expose controls on case pages
- Future Systems remains labeled R&D
- Contact email is tested
- Custom domain HTTPS is active

## 6. Google Search identity

- Company-mark icons are generated by `node scripts/generate-icons.mjs` and committed with the source. `/favicon.ico`, `/icons/favicon-96.png`, and the formerly published `/icons/favicon.svg` all use the company mark.
- The homepage carries the approved Google Search Console HTML verification tag. Retain it after verification.
- Homepage metadata and Organization/WebSite structured data describe current services separately from satellite R&D. Do not claim a completed satellite product.
- After publishing, use the verified `https://grashofstudio.com/` Search Console property to request homepage indexing and submit `sitemap.xml`.
- Google controls search titles, favicon selection, and AI summaries; a successful deploy or indexing request does not mean search results have refreshed.
