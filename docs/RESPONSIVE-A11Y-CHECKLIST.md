# Responsive and Accessibility Checklist

## Viewports

- 375 px — single-column layout, no horizontal overflow
- 768 px — tablet navigation and media layout
- 1024 px — compact desktop / landscape tablet
- 1440 px — full cinematic composition

## Interaction

- Mobile navigation opens from a 44 × 44 px control
- Escape closes mobile navigation
- Clicking outside closes mobile navigation
- Focus styles are visible
- Email and project links are keyboard accessible

## Motion

- `prefers-reduced-motion` disables starfield and reveal motion
- Autoplay videos are muted
- Autoplay videos pause when reduced motion is requested
- Project-page videos expose native controls

## Semantics

- One H1 per page
- Project media has meaningful labels or alt text
- Decorative planetary imagery uses empty alt text
- Navigation and project sections use semantic elements
